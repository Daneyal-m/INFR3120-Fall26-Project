# FixIT - Campus IT Helpdesk

## Project Description 

FixIT is a website that helps students with their IT problems at their campus. They can submit tickets for problems such as software issues and hardware issues. The IT team can check the submitted tickets and see which problems need to be fixed.

## Features

- Student can submit tickets for their IT problems.
- Student can enter the title and description of the issue.
- Students can pick the problem category.
- Students can enter the location of the problem.
- Students can choose how urgent their problem is.
- The IT team can check all submitted tickets.

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- EJS
- MongoDB

## How to Run the Project

1. First, we have to clone the project from GitHub:

git clone https://github.com/Daneyal-m/INFR3120-Fall26-Project.git  

2. We have to open the project folder: 

cd INFR3120-Fall26-Project

3. We have to install the packages we need: 

npm install

4. We can start the application: 

npm start

5. Last, open the browser: 

http://localhost:3000
